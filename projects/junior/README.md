# Junior track

Three portfolio options: **applied ML**, **RAG**, and **football video AI** (YOLO upstream + optional **AI commentator** with TTS, EN/AR, DB, and **three submission levels**). Pick **one** project and ship it with a **`prompts/`** folder—see [projects/README.md](../README.md).

| # | Focus | Link |
|---|--------|------|
| **1** | **Applied ML / NLP** — recommendation, CNN, or sentiment; evaluation; **Streamlit** (or similar) demo | [Project 1](1/README.md) |
| **2** | **RAG app** — PDFs/docs, embeddings, vector DB, LLM API, optional memory | [Project 2](2/README.md) |
| **3** | **Football AI** — [**football_analysis**](https://github.com/MuhammadMoinFaisal/football_analysis) vision backbone; optional full **commentator** (LLM, TTS, DB, EN+AR, Flask → WebSocket → dynamic controls) | [Project 3](3/README.md) |

## Where to put your code

`projects/junior/<your-slug>/` with a project `README.md` and **`prompts/`** (required).
